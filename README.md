# 🏨 Sistema de Hotel em Java

Este é um projeto simples feito em Java para simular o funcionamento básico de um sistema de hotel.  
O sistema permite **cadastrar hotéis e clientes**, adicionar quartos e gerar reservas com data de entrada e saída.  
Ideal para fins educacionais e aprendizado de orientação a objetos em Java.  

---

## Funcionalidades

- Cadastro de hotel (nome e endereço)
- Cadastro de quarto (número e tipo)
- Cadastro de cliente (nome, CPF e e-mail)
- Criação de reserva com data de início e término
- Exibição das informações do hotel, cliente, quarto e reserva

---

## Estrutura do Projeto

O projeto é composto pelas seguintes classes:

- `Main` — Classe principal com a lógica de entrada de dados e simulação da reserva
- `Hotel` — Representa o hotel e armazena a lista de quartos
- `Quarto` — Representa um quarto do hotel com número, tipo e status de ocupação
- `Cliente` — Contém informações do hóspede
- `Reserva` — Representa a reserva de um quarto por um cliente em um período

---

## 🛠️ Tecnologias Utilizadas

- **Java** — Programação Orientada a Objetos  
- **Scanner** — Entrada de dados via terminal  
- **IntelliJ IDEA** (IDE utilizada para desenvolvimento)
